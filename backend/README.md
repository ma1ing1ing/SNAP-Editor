# SNAP-Editor Backend

이 폴더(`backend`)는 AI를 활용하여 긴 영상에서 무음 구간을 자동으로 탐지 및 제거하고, 정밀한 자막을 생성하여 최종 컷편집 영상을 만들어내는 자동화 파이프라인의 핵심 로직을 포함하고 있습니다.

## 주요 기능 (Pipeline)

전체 작업 흐름은 `main.py`에 의해 순차적으로 실행되며, 다음 단계로 구성됩니다:

1. 오디오 추출 (Audio Extraction):** 영상 파일에서 오디오만 분리하여 분석에 최적화된 포맷(16kHz, mono)으로 추출합니다. 동시에 오디오 싱크 밀림을 방지하기 위한 보정 작업을 수행합니다.
2. 무음 탐지 (VAD - Voice Activity Detection):** AI 모델(`silero-vad`)을 활용하여 목소리가 있는 구간과 없는 구간(무음)을 정밀하게 구분합니다.
3. 파형 시각화 (Waveform Viewing):** 추출된 오디오 파형과 탐지된 무음 구간을 시각화하여 사용자가 확인할 수 있도록 창을 띄웁니다.
4. 컷 편집 (Cut Editing): 탐지된 무음 구간 데이터를 바탕으로 FFmpeg을 이용해 원본 영상을 분할 렌더링 후 병합하여 무음이 제거된 편집본을 만듭니다. 이 과정에서 프레임 레이트와 오디오 타임스탬프를 고정하여 싱크 오류를 방지합니다.
5. 자막 생성 (Transcription):** `stable-ts` (Whisper 기반) 모델을 통해 편집된 영상의 음성을 텍스트로 변환하고 `kiwipiepy`를 이용해 한국어 마침표 보정 등을 수행하여 정밀한 자막 파일(.srt)을 생성합니다.
6. 최종 결과물 생성: 컷편집된 영상에 생성된 자막을 소프트 인코딩 방식으로 병합하여 최종 영상 결과물을 만들어냅니다.

## 파일 설명

- `main.py`: 전체 자동 편집 파이프라인의 진입점(Entry point)입니다. 모든 모듈을 호출하여 순차적으로 작업을 수행합니다.
- `extract_audio.py`: 영상을 입력받아 음성 인식에 최적화된 오디오 파일(wav)을 추출합니다. (FFmpeg 사용)
- `vad_tagger.py`: Silero VAD 모델을 로드하여 오디오에서 사람의 목소리를 감지하고 무음 구간의 타임스탬프를 리스트로 반환합니다.
- `viewer.py`: `librosa`와 `matplotlib`를 사용하여 오디오 파형과 AI가 찾아낸 무음 구간을 화면에 그래픽으로 표시해줍니다.
- `editor.py`: 영상 자르기 및 병합(FFmpeg 활용), 그리고 영상과 자막 파일(.srt)을 하나로 합치는 소프트 인코딩 기능을 담당합니다.
- `transcriber.py`: Whisper(stable-ts) 모델로 음성을 텍스트로 변환(STT)하고, 자연스러운 자막 파일(.srt)을 생성합니다.
- `export_json.py`: VAD 분석을 수행한 뒤 그 결과(목소리 구간, 무음 구간 타임스탬프)를 JSON 파일로 내보내는 유틸리티 스크립트입니다.
- `download_video.py`: `yt-dlp`를 사용하여 테스트용 유튜브 영상을 다운로드할 수 있는 스크립트입니다.
- `test_cut.py`: (테스트용) 특정 구간이나 기능만 분리해서 컷 편집이 잘 되는지 확인할 때 사용되는 스크립트입니다.

## 데이터 폴더 (`Data/`)

분석할 원본 영상, 추출된 오디오, 생성된 자막 파일(srt), 영상 렌더링용 임시 폴더 및 최종 렌더링 파일들이 저장되는 공간입니다.
