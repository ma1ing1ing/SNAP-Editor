# SNAP-Editor Backend

이 폴더(`backend`)는 AI를 활용하여 긴 영상에서 무음 구간을 자동으로 탐지 및 제거하고, 정밀한 자막을 생성하여 최종 컷편집 영상을 만들어내는 자동화 파이프라인의 핵심 로직을 포함하고 있습니다.

## 주요 기능 (Pipeline)

전체 작업 흐름은 `main.py`에 의해 순차적으로 실행되며, 다음 단계로 구성됩니다:

1. 오디오 추출 (Audio Extraction):** 영상 파일에서 오디오만 분리하여 분석에 최적화된 포맷(16kHz, mono)으로 추출합니다. 동시에 오디오 싱크 밀림을 방지하기 위한 보정 작업을 수행합니다.
2. 무음 탐지 (VAD - Voice Activity Detection):** AI 모델(`silero-vad`)을 활용하여 목소리가 있는 구간과 없는 구간(무음)을 정밀하게 구분합니다.
3. 파형 시각화 (Waveform Viewing):** 추출된 오디오 파형과 탐지된 무음 구간을 시각화하여 사용자가 확인할 수 있도록 창을 띄웁니다.
4. 컷 편집 (Cut Editing): 탐지된 무음 구간 데이터를 바탕으로 FFmpeg을 이용해 원본 영상을 분할 렌더링 후 병합하여 무음이 제거된 편집본을 만듭니다. 이 과정에서 프레임 레이트와 오디오 타임스탬프를 고정하여 싱크 오류를 방지합니다.
5. 자막 생성 (Transcription):** `stable-ts` (Whisper 기반) 모델을 통해 편집된 영상의 음성을 텍스트로 변환하고 `kiwipiepy`를 이용해 한국어 마침표 보정 등을 수행하여 정밀한 자막 파일(.srt)을 생성합니다.
6. 최종 결과물 생성: 컷편집된 영상에 생성된 자막을 소프트 인코딩 방식으로 병합하여 최종 영상 결과물을 만들어냅니다.

## 파일 설명

- `main.py`: 전체 자동 편집 파이프라인의 진입점(Entry point)입니다. 모든 모듈을 호출하여 순차적으로 작업을 수행합니다.
- `backend_controller.py`: PyQt6 프론트엔드 등 외부 UI와 비동기적으로 연동하기 위해 전체 파이프라인을 단계별(Step-by-Step)로 모듈화한 백엔드 메인 컨트롤러입니다. 콜백(Callback) 함수를 통해 진행 상태(Progress)와 로그를 실시간으로 전달합니다.
- `extract_audio.py`: 영상을 입력받아 음성 인식에 최적화된 오디오 파일(wav)을 추출합니다. (FFmpeg 사용)
- `vad_tagger.py`: Silero VAD 모델을 로드하여 오디오에서 사람의 목소리를 감지하고 무음 구간의 타임스탬프를 리스트로 반환합니다.
- `viewer.py`: `librosa`와 `matplotlib`를 사용하여 오디오 파형과 AI가 찾아낸 무음 구간을 화면에 그래픽으로 표시해줍니다.
- `editor.py`: 영상 자르기 및 병합(FFmpeg 활용), 그리고 영상과 자막 파일(.srt)을 하나로 합치는 소프트 인코딩 기능을 담당합니다.
- `transcriber.py`: Whisper(stable-ts) 모델로 음성을 텍스트로 변환(STT)하고, 자연스러운 자막 파일(.srt)을 생성합니다.
- `export_json.py`: VAD 분석을 수행한 뒤 그 결과(목소리 구간, 무음 구간 타임스탬프)를 JSON 파일로 내보내는 유틸리티 스크립트입니다.
- `download_video.py`: `yt-dlp`를 사용하여 테스트용 유튜브 영상을 다운로드할 수 있는 스크립트입니다.
- `test_cut.py`: (테스트용) 특정 구간이나 기능만 분리해서 컷 편집이 잘 되는지 확인할 때 사용되는 스크립트입니다.

## 데이터 폴더 (`Data/`)

분석할 원본 영상, 추출된 오디오, 생성된 자막 파일(srt), 영상 렌더링용 임시 폴더 및 최종 렌더링 파일들이 저장되는 공간입니다.

## 예상되는 오류 및 해결 방법 (Troubleshooting)

백엔드 파이프라인을 실행하는 과정에서 발생할 수 있는 주요 오류와 해결 방법입니다.

### 1. 모듈 및 라이브러리 임포트 오류 (ModuleNotFoundError)
- **오류:** `No module named 'stable_ts'`, `No module named 'librosa'`, `No module named 'ffmpeg'` 등
- **원인:** 필요한 파이썬 라이브러리가 현재 가상환경에 설치되지 않았습니다.
- **해결:** 프로젝트 요구사항에 맞는 패키지 설치가 필요합니다. 참고로 파이썬용 `ffmpeg-python` 라이브러리와 실제 OS의 `ffmpeg` 프로그램은 별개이므로 둘 다 설치되어 있어야 합니다.

### 2. FFmpeg 시스템 오류 (FileNotFoundError / ffmpeg.Error)
- **오류:** `ffmpeg` 명령어를 찾을 수 없거나, 추출 및 렌더링 중 에러 발생
- **원인:** OS 자체에 FFmpeg가 설치되어 있지 않거나 환경 변수(PATH)에 등록되지 않았을 때 발생합니다.
- **해결:** macOS의 경우 `brew install ffmpeg` 명령어로 시스템 FFmpeg를 설치해야 합니다.

### 3. 파일 경로 오류 (FileNotFoundError)
- **오류:** `❌ 에러: '...' 파일을 찾을 수 없습니다.` 또는 임시 파일 로드 실패
- **원인:** `INPUT_VIDEO`로 지정된 원본 영상이 없거나, 이전 단계가 실패하여 다음 단계에서 필요한 임시 파일(`temp_audio.wav`, `cut_analysis.json` 등)이 생성되지 않았기 때문입니다.
- **해결:** 원본 파일의 위치를 재확인하고, 파이프라인의 이전 단계가 정상적으로 끝났는지 로그를 점검합니다.

### 4. AI 모델 다운로드 오류 (Network / Timeout)
- **오류:** `torch.hub.load` (VAD) 또는 `stable-ts` (Whisper STT) 실행 중 인터넷 접속 오류
- **원인:** 모델을 처음 다운로드할 때 인터넷 연결이 불안정하거나 방화벽에 막힌 경우입니다.
- **해결:** 인터넷 연결을 확인한 뒤 재시도합니다. (최초 1회만 다운로드하며 이후에는 로컬 캐시를 사용합니다.)

### 5. 자막 병합 및 인코딩 오류 (Codec Error / Subprocess)
- **오류:** `❌ 자막 추가 실패` 후 재시도 로그 출력
- **원인:** MP4에서 사용하는 `mov_text` 자막 코덱이 영상과 호환되지 않는 상황입니다.
- **해결:** `editor.py` 내부에 `srt` 코덱으로 재시도하는 예외 처리가 마련되어 있습니다. 만약 모두 실패한다면 영상 포맷 자체의 문제일 수 있습니다.

### 6. 스레드/GUI 관련 오류 (Matplotlib)
- **오류:** `viewer.py` 실행 시 화면이 멈추거나 백엔드 크래시 발생
- **원인:** `matplotlib`의 창(`plt.show()`)을 띄우는 작업이 PyQt6 등의 워커 스레드(Sub Thread)에서 실행될 경우 충돌이 일어납니다 (특히 macOS).
- **해결:** `backend_controller.py`의 Step 2(뷰어) 기능은 프론트엔드 연동 시 반드시 **메인 스레드(Main Thread)**에서 직접 호출하도록 구현해야 합니다.
